Savor

A pantry that knows what you have, and what is about to go bad.

About 38% of the US food supply goes uneaten — roughly $473 billion a year, and the single largest category in landfill. Savor photographs your receipt, reads it with Gemini’s vision model and turns it into an inventory; then it suggests meals built around whatever is closest to expiring, and keeps a running tally of the CO₂ and the money you didn’t throw away. Built over one weekend at HenHacks 2026 with three teammates, none of whom had written a React component before Friday.

022026research

Dog keypoints, in two stages

39 body keypoints and 46 facial landmarks on a moving dog.

A cascade: DeepLabCut’s published SuperAnimal-Quadruped checkpoint runs frozen and unmodified to find the body and the head, a derived face box crops to 256×256, and a second model trained on DogFLW reads the face. The invariant that made it work is that training and inference derive the face box through the same function — there is a test that asserts both call sites resolve to the same object — so the face model never sees a crop distribution it wasn’t trained on. Against the previous single unified model, on 479 held-out images: mean NME −28.6%, PCK@5% 71.0 → 84.1. Every facial region improved; the muzzle by 57%.

The site you are reading, and the computer reading it to you.

Hand-written HTML, CSS and JavaScript — no framework, no build tool but one short Python script, no node_modules. 042026Raspberry Pi

Oracle

Something that lives on a Minecraft server and has been paying attention.

A Java plugin on a Paper server running on a Raspberry Pi 4B. Oracle has no command and no prefix: it reads all public chat, scores every line 0–100 for whether it is worth answering, and speaks when a line clears the threshold and it is off cooldown. It notices deaths, death streaks, advancements, dimension changes, and slower things — somebody circling the same hill for fifteen minutes — and each one is news exactly once. It will tell you where you last died and roughly which way the nearest village is, as a direction and a distance, never as coordinates. The model behind it is swappable mid-flight between Claude, Gemini and the Jetson downstairs; the personality stays on the Pi, so it is the same Oracle whichever answers. It is quiet most of the time. That is the design.

052026CISC 442

Dog gait CCL classifier

Point it at a video of a dog walking; it tells you whether the knee is torn.

A cranial cruciate ligament rupture is the most common orthopaedic injury in dogs and it is diagnosed by eye. This pipeline runs pose estimation over a lateral gait video, turns the joint trajectories into gait features and classifies CCL against normal with a random forest trained on 12 GB of clinical video. It refuses videos that aren’t shot side-on unless you override it, and writes a pose-overlaid copy of the input so you can see what the model was actually looking at rather than trusting the number.

072026open problem

The World Cup polynomials

Counting every way a round-robin tournament can finish dead level.

Given n teams who all play each other, how many ways can every team finish with exactly r goals for and r against? The count is the Ehrhart polynomial of the zero-diagonal face of the Birkhoff polytope. Doron Zeilberger posed it as a challenge in June 2026 with his computer having reached n = 6. Inclusion–exclusion on the diagonal, run out far enough to interpolate, produced n = 7 (degree 29) and n = 8 (degree 41), verified against independent counts and sent to him.

MNIST, with nothing underneath it but a compiler.

102026one file

pimon

A terminal dashboard that compiles itself the first time you run it.

One C file with a shebang line that builds and caches its own binary, then charts SoC temperature, CPU and memory over a rolling window. No ncurses and no runtime: metric files are opened once and re-read with pread(), so a sample costs a handful of syscalls and no fork, and between samples the process sits in poll() burning nothing. No allocations after startup, about 600 KB resident. It was built to monitor a busy Raspberry Pi without becoming the reason the Pi is busy.
