Savor

A pantry that knows what you have, and what is about to go bad.

About 38% of the US food supply goes uneaten — roughly $473 billion a year, and the single largest category in landfill. Savor photographs your receipt, reads it with Gemini’s vision model and turns it into an inventory; then it suggests meals built around whatever is closest to expiring, and keeps a running tally of the CO₂ and the money you didn’t throw away. Built over one weekend at HenHacks 2026 with three teammates, none of whom had written a React component before Friday.

Dog keypoints, in two stages

39 body keypoints and 46 facial landmarks on a moving dog.

DeepLabCut’s published SuperAnimal-Quadruped checkpoint runs frozen and unmodified to find the body and the head; a derived face box crops to 256×256; a second model trained on DogFLW reads the face. What made it work is that training and inference derive that box through the same function — there is a test asserting both call sites resolve to the same object — so the face model never meets a crop distribution it wasn’t trained on. Against the previous single unified model, on 479 held-out images: mean NME −28.6%, PCK@5% 71.0 → 84.1. Every facial region improved; the muzzle by 57%.

gabevandevere.com

The site you are reading, and the computer reading it to you.

Hand-written HTML, CSS and JavaScript — no framework, no build step but one short Python script, no node_modules. Caddy serves it from a Jetson Orin Nano Super on my desk through an outbound-only Cloudflare tunnel, so nothing forwards a port. The model you can talk to below is a 9-billion-parameter open model on that board’s GPU, behind a Python proxy that holds the key, caps output and queues callers against the single inference slot. One command builds, reloads, smoke-tests local and live, refuses to commit anything shaped like a secret, and mirrors to GitHub.
