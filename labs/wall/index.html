volume 02 · 2026research

Dog gait analysis

Detects cranial cruciate ligament injury from video of a dog walking.

Two stages: a pose cascade tracks 39 body keypoints and 46 facial landmarks per frame, cutting mean normalised landmark error 28.6% against the previous single-model approach (PCK@5% 71.0% to 84.1%, 479 held-out images). Those joint trajectories become gait features for a random-forest classifier trained on 12 GB of clinical video. Output is a CCL probability and a pose-overlaid render of the input for review.

volume 03 · 2026Raspberry Pi

Oracle

Minecraft server on a Raspberry Pi with an autonomous chat agent.

Paper server on a Raspberry Pi 4B, exposed over an outbound tunnel rather than port forwarding and managed by systemd so the world saves before a restart. Oracle is a Java plugin that reads all public chat with no command prefix: an interest scorer rates every message 0–100, and it replies only when the score clears a threshold and a cooldown has elapsed. The inference provider — Claude, Gemini, or llama.cpp on the Jetson — is switchable at runtime.
